# industry-analysis-framework

行业分析快速上手框架 —— 一个 Hermes Agent Skill。

把《如何快速了解一个行业》（肖璟）的读书笔记提炼成可执行的流程与判据，用于：

- 了解一个此前不熟悉的行业 / 赛道
- 判断某个赛道值不值得投入（产品立项、转岗、投资）
- 给行业分析报告或面试题搭骨架
- 验证别人给的行业结论（研报、新闻、AI 回答）站不站得住

## 核心设计

行业分析的关键不是把资料堆齐，而是**先定位阶段，再决定研究什么**。同一个「这个行业怎么样」的问题，导入期要答的是商业模式能不能成立，成熟期要答的是护城河够不够宽——用错阶段的问题清单，报告再长也没用。

所以这个 skill 的骨架是「阶段 → 问题清单 → 判据」，而不是知识点清单。

## 五步流程

| 步骤 | 产出 | 完成标准 |
| --- | --- | --- |
| 1 界定研究对象 | 一句话研究对象 | 写明口径（国标 / 证监会 / 申万）、边界、上下游范围 |
| 2 定位生命周期 | 阶段 + 渗透率 | 附渗透率数字、口径说明、数据来源 |
| 3 按阶段研究 | 该阶段的问题清单答案 | 导入期看商业模式与 UE 三模型；成长期算市场规模；成熟期判护城河；衰退期看集中度与产能周期 |
| 4 分阶段估值 | 用哪类估值逻辑 | 说明为什么用 / 不用市盈率 |
| 5 动态追踪 | PEST + 景气度指标 | 给出先行指标与确认指标 |

## 内容要点

| 部分 | 一句话 |
| --- | --- |
| 研究对象界定 | 国标 / 证监会 / 申万三套口径不可混用，混口径是最常见的错 |
| 生命周期 | 渗透率 = 存量用户 ÷ 潜在用户；15%–20% 提速，35%–40% 后放缓（阈值必须连口径一起写） |
| 导入期 | 需求是否真实存在 + 盈利能否复制；UE 三模型（当前 / 盈亏平衡 / 终局） |
| 成长期 | 规模 = 目标客户数 × 渗透率 × 客均订单量 × 客单价；供需匹配法只能在成熟期用 |
| 成熟期 | 护城河 = 独占生产要素（→ 更高营收）或独占生产关系（→ 更低成本）；必须做动态复核 |
| 衰退期 | CR8 四类型对应四种定价逻辑；资本性支出 ÷ (折旧+摊销) < 1.5 是供给底部信号 |
| 估值 | 行业相对估值 = 行业市盈率 ÷ 全部 A 股市盈率；成长期景气度优先于估值 |
| 研报筛选 | 四看：热度 → 团队 → 推荐 → 内容 |
| AI 辅助 | 假设 → MECE 拆解 → 验证子假设；输出用 SCQR（空雨伞） |
| 常见坑 | 10 条，含「把宏观 beta 当行业 alpha」「CRn 只覆盖上市公司低估集中度」 |

## 怎么用

**在 Hermes 里**：把 `SKILL.md` 与 `references/` 放到 `~/.hermes/skills/research/industry-analysis-framework/` 下，之后提到「分析某个行业 / 这个赛道值不值得进」时会自动加载。

**手工查**：先读 SKILL.md 的 Step 1–2 定位阶段，再跳到你所在阶段的那一节当问题清单用；末尾的交付模板可直接套。

## 说明与边界

- 原始素材是**读书笔记**（《如何快速了解一个行业》，肖璟，中信出版集团），不是原书全文。条目取舍按「能不能改变行动」筛选，原书案例只保留新能源汽车一个。
- 书里的金融/投资视角较重。做**产品视角**的行业分析时，Step 3 的成长期（市场规模 + 三障碍找机会）与成熟期（护城河）最有用，Step 4 的估值部分可略读。
- 数据与时效：书中的经验阈值（15%–20%、35%–40%、CR8 分型、资本性支出比 1.5）是经验值，不是定律；引用前先确认口径与年份。
- 取数与检索的执行细节（受限网络下的可用入口、反爬、抓正文）见另一份 skill `cn-industry-research`。

## 更新建议

每做完一个真实行业分析就回来补一次：把新踩的坑加进「常见坑」，把新验证过的判据补进对应步骤。方法论的寿命取决于它是否被真实项目持续校准。
