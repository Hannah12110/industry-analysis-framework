# 研究工具箱：完整机构与工具清单

来源：《如何快速了解一个行业》（肖璟）研究工具篇。用来在 Step 1–5 取数时定位「去哪找」，取数执行细节（反爬、API、抓正文）见 skill `cn-industry-research`。

## 一、统计机构

### 国务院组成部门

| 机构 | 能拿到什么 |
|---|---|
| 国家发展和改革委员会 | 分省份/地区经济数据、煤电油气运行数据、物流仓储数据、重要商品价格、粮食收购进度 |
| 教育部 | 学校/教师/学生数量、专业招生情况 |
| 工业和信息化部 | 原材料工业、装备工业、消费品工业、通信业、电子信息制造业、软件业、互联网、网络安全统计 |
| 财政部 | 财政预算结算、税收、土地出让金、央国企运营情况、彩票销售 |
| 人力资源和社会保障部 | 就业数据、社保数据 |
| 自然资源部 | 土地数据、矿产数据、海洋统计报告、测绘、地质数据 |
| 生态环境部 | 生态环境统计年报 |
| 住房和城乡建设部 | 城乡建设统计年鉴、建筑业数据 |
| 交通运输部 | 水运、公路、铁路、民航、邮政、城市客运、港口、投资、运价指数 |
| 农业农村部 | 农产品价格、农产品进出口数据 |
| 商务部 | 国际投资数据、国际业务数据、国际贸易简况 |
| 国家卫生健康委员会 | 国家基本药物目录、医卫机构名单 |
| 中国人民银行 | 社会融资规模、货币供给、金融业数据、金融市场统计、银行家/企业家调查问卷、货币政策 |

### 国务院直属机构

国家金融监督管理总局（银行业、保险业）、中国证监会（证券/期货市场数据、合法机构名录）、国家体育总局（国民体质监测）、国家统计局（各类宏观数据）、国家医疗保障局（医疗保险、生育保险）。

### 国务院部委管理的国家局

国家铁路局（铁路发送量）、中国民用航空局（民航主要生产指标）、国家邮政局（邮政行业运行）、国家外汇管理局（国际收支平衡表、结售汇、官方储备资产）。

### 协会与其他

中国外汇交易中心（货币市场报价利率、债券市场价格、外汇市场价格）、中国证券投资基金业协会（基金资管规模、规模排名、类型分布）、中国债券信息网（债券收益率、债券指数）、中国互联网络信息中心（互联网发展状况统计）、上交所、深交所、中国汽车工业协会、乘用车市场信息联席分会。

### 国际官方机构

世界银行、国际货币基金组织、经济合作与发展组织、国际清算银行、国际能源署（能源供需/进出口/价格/排放）、联合国粮食及农业组织（245+ 国家和地区粮食与农业数据）。

| 卖方机构 | 券商、投行 —— 见下方四类研报 |

### 卖方四类研报

- **宏观研报**：分析 PMI、工业增加值、进出口、CPI、PPI 等指标 + 跟踪货币/财政政策 → 判断经济周期阶段、未来方向、宏观流动性松紧、大类资产配置
- **策略研报**：偏中观 —— 大势研判、行业比较、主题投资建议
- **行业研报**：商业模式、产业链上下游、竞争格局、未来发展空间、投资价值、行业内上市公司特点与优势
- **公司研报**：单一公司的历史背景、治理结构、商业模式、核心优势、盈利状况
